# anvilborn-legal

The published legal pages for the ANVILBORN Android app.

`index.html` is generated from `src/features/legal/policy.ts` in the app
repository by `npm run legal` — edit it there, never here, so the page and
the copy shown inside the app can never disagree.

Published at <https://cma-uplink.github.io/anvilborn-legal/>.
